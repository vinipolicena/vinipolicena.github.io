# Hugo Site

This is a basic Hugo site.

## Getting Started

To run this site locally, you need to have Hugo installed. You can find installation instructions on the [Hugo website](https://gohugo.io/getting-started/installing/).

Once Hugo is installed, you can run the site locally using the following command:

```bash
hugo server -D
```

This will start a local server and you can view the site in your browser at `http://localhost:1313/`.

## Content

The content for this site is located in the `content` directory. You can add new content by creating new Markdown files in this directory.

## Themes

This site uses the Ananke theme. The theme is located in the `themes/ananke` directory. You can find more information about the Ananke theme on its [GitHub page](https://github.com/theNewDynamic/gohugo-theme-ananke).
